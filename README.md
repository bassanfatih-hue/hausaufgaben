# Hausaufgaben-Planer

Eine Seite zum Eintragen und Abhaken von Hausaufgaben, Tests und To-dos, mit Übersicht nach Fälligkeit.

Seite: https://bassanfatih-hue.github.io/hausaufgaben/

Die Einträge liegen nicht hier, sondern im privaten Repo `hausaufgaben-daten` (Datei `eintraege.json`).
Jedes Gerät braucht einmal einen Schlüssel (fine-grained Token mit Zugriff nur auf `hausaufgaben-daten`, Contents: Read and write).
